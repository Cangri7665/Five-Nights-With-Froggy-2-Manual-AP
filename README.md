# Archipellago manual: Five nights with froggy 2
A pretty niche fnaf-inspired russian game with some assasins plushies

## Checks:
- Completing a night
- Getting a jumpscare for all characters (Jumpscaresanity, can de disabled, disabled by default)
- Completing a challenge (Can be disabled, enabled by default)
- Completing custom night 20 IA level with all the amount of characters (1/20, 2/20, etc.)
- Completing one of the special nights (Can be disabled, disabled by default)
- Getting an ending
- Getting screwdiver and music box
- Getting a find in the bottle minigame
- Winning the grandma in law and lorenzi minigame

## Items:
- Nights's access
- Screwdiver
- Music box
- Characters's access in custom night
- Bottle Minigame's access
- Answers's access

## Goal(s):
Completing Saturday
Getting interrupted arrest ending (13/20)
Getting the end of the palace ending (13/20)

Note: The endings can be chosen in the yaml
